FinTrack Full Upgrade v2

Includes Nepali and English interface plus Korean translations for key navigation and finance labels; manual income/expense entry; receipt photo OCR attempt (Nepali/English/Korean); gallery/photo selection; PDF file selection with manual amount entry; transaction editing/deletion; reports; backup/export; PWA files.

Important limitations: OCR depends on network access and browser support and must be checked before saving. PDF upload in this version selects the PDF and opens manual expense entry; it does not automatically extract PDF text. The language menu offers Nepali, English and Korean; it does not yet translate every possible screen string or support every world language.

Deploy: Extract this ZIP and upload the CONTENTS (index.html, sw.js, manifest.webmanifest, icon.svg, README.txt) to the root of the existing GitHub Pages repository, then commit. Keep a backup first.
