FinTrack starter app

This is a starter Progressive Web App (PWA), not yet a published app.
To install on iPhone:
1. Publish the extracted folder to an HTTPS static hosting service.
2. Open the published website in Safari.
3. Tap Share, then Add to Home Screen, then Add.

On Android:
1. Open the published website in Chrome.
2. Choose Install app or Add to Home screen.

Income, Expense, Loan and Savings entries are stored locally in this browser on this device.
This starter does not yet include cloud sync, password protection, Excel export, or full Nepali translation.
The mountain header photo requires an internet connection on first load.
